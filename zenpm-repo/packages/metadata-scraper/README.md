# Metadata Scraper

Metadata Scraper is a KOReader plugin for finding EPUB metadata and covers from Hardcover, Amazon Creators API, Google Books, and Open Library.

It writes KOReader-native custom metadata and custom covers. The normal workflow does not rewrite EPUB files.

## Requirements

- KOReader 2026.07 or newer
- Network access for online metadata searches
- Optional provider credentials for Hardcover, Amazon Creators API, and Google Books

## After installation

Open **Tools → Metadata Scraper** in KOReader. Open **Provider accounts** to configure optional API credentials and test provider connectivity.

Project source and full documentation: https://github.com/JDsnyke/koreader-metadata-scraper
